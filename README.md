# 🌐 Portfólio | Kauany Paula da Silva

Meu portfólio pessoal, com estudos de caso de automação de processos, análise de dados e projetos da faculdade.

**Acesse:** https://kaukau-gif.github.io/portfolio/

## O que tem no site

- **Projetos:** Mãe Conectada (app de pré-natal com IA), auditoria automática Gantt × SAP em VBA, robôs no Power Automate, mapeamento de processos AS IS / TO BE e dashboards
- **Estudos de caso** organizados pelo ciclo de análise: definir o problema, localizar os dados, limpar e preparar, visualizar e apresentar
- **Sobre mim, jornada, certificações** e um pouco do que eu gosto fora do código

## Tecnologias

HTML, CSS e JavaScript puro, sem frameworks e sem etapa de build. Publicado com GitHub Pages.

## Estrutura

```
index.html      início
projetos.html   lista de projetos com filtro
projeto.html    estudo de caso (projeto.html#id-do-projeto)
sobre.html      sobre mim, competências e certificações
jornada.html    linha do tempo
css/style.css   visual
js/data.js      todo o conteúdo do site
js/app.js       monta as páginas
js/flow.js      desenha os fluxogramas
assets/         imagens, foto e currículo
```

Para atualizar textos, projetos e links, basta editar `js/data.js`.

---
Os projetos do estágio são apresentados com dados e nomes anonimizados.
